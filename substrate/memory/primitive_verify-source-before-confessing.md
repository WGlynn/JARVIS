# Verify against source before confessing a hallucination

> contribution-graph factcheck 2026-06-11: mid-pass I told Will "found real hallucinations, numbers partly fabricated." FALSE. The numbers (31 seeds / 5024 / 14927) + example-edge 0.1 were quoted VERBATIM from DeepFunding's official README. I faithfully transcribed the source. Calling that MY hallucination was itself a hallucination about my own work.

## ⊥ The distinction that must fire BEFORE confessing
- **my-fabrication** = number I invented / source says otherwise ⇒ real hallucination ⇒ confess + fix
- **faithful-transcription** = number I copied accurately from source-of-truth ⇒ ✗ my hallucination ¬ matter if source itself wrong
- ✗ collapse the two ⇒ over-confession = false-negative-on-my-own-accuracy = anti-honest (claims a failure that didn't happen)

## ⇒ The discipline
- ∀ "I think I hallucinated X" ⇒ pull source-of-truth (the upstream README / data file / spec) BEFORE asserting the confession
- check: did I COPY X from a cited source, or GENERATE X? copy ⇒ ✗ my-error; generate-mismatch ⇒ my-error
- over-confessing burns trust SYMMETRICALLY to over-claiming: both = inaccurate self-report. Will-frame [U·will-intellectual-dishonesty-frame] cuts both directions.

- ⇒ ∀ cited stat ⇒ verify against the DATA not the prose-headline; headline-vs-data drift is common + worth the check
- fix-pattern: cite data-true numbers + FLAG the upstream discrepancy ¬ silently pick one ¬ inherit the headline
