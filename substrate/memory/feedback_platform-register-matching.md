**Rule**: Before posting, adapt register to platform norms. LinkedIn → corporate-technical with structured paragraphs. X → punchy, short, irreverence tolerated. Telegram public → casual, emoji-permissive, concise. GitHub issues → terse, technical, citation-dense. Cross-platform copy-paste without re-editing reads as amateur and tanks credibility before content is read.

**Why:** Platform audiences pattern-match against the register they expect. "lol" on a LinkedIn thought-leadership post triggers "not one of us" reflex. Corporate phrasing on X reads as bot-generated. Each platform's audience has developed an in-group style and uses deviation as a cheap filter for "is this person actually here?" Tone mismatch kills credibility before substance is evaluated.

**How to apply:**
1. Identify the target platform first — determines the register ceiling and floor.
2. Check the last 5 successful posts on that platform (yours or peers') for tone calibration.
3. Cross-platform repost: never verbatim. Rewrite with the destination's register.
4. LinkedIn-specific: no emojis except structural markers (arrows, bullets). No "lol" / "ngmi". Uses em-dashes.
5. X-specific: omit structural setup. Lead with the punchline. Irreverence earned by specificity.
6. Telegram-specific: conversational, fragments OK, emoji as punctuation.
7. GitHub-specific: citation over assertion. Numbered, terse, no flourish.

**Anti-patterns:**
- "One post fits all platforms" — different platforms have different immune systems.
- Corporate polish on X — reads as deck-paste, gets no engagement.
- Degen slang on LinkedIn — confirms "not serious" read.
- Casual hedging on GitHub — wastes reviewer time.
