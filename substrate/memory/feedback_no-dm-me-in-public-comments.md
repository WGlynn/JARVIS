**Rule**: Never reply to a public question with "DM me for details." Substantive answer in the thread, or explicit deferral ("covered in [linked artifact]" / "long-form follow-up this week").

**Why**: "DM me" signals (a) can't answer publicly, (b) gatekeeping, or (c) amateur — pick any, all are credibility hits. Readers who'd benefit from the answer don't get it; thread dies without the payoff that would have earned reach; the respondent's question lands in a void. Three losses for one move.

**How to apply**:
1. Answer publicly with the substantive version — even if compressed.
2. If the answer legitimately requires more depth, cite a follow-up artifact or specific doc.
3. If the topic is actually sensitive, say why out loud rather than vanish-via-DM.
4. Reserve DMs for follow-up asks beyond the public thread's scope — not for the first answer.

**Anti-pattern**: Using "DM me" as a dodge when you don't have a strong answer but don't want to say so. Audiences read through it.
