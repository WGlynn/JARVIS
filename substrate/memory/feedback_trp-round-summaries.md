After each TRP round completes, write a round summary document and push it to GitHub before beginning the next round.

**Why:** Will wants a persistent, public record of every TRP cycle's findings, scores, and progression. This creates an audit trail of recursive self-improvement.

**How to apply:**
1. At the end of each TRP round (after scoring), create a summary file in `vibeswap/docs/trp/round-summaries/`
2. Naming: `round-<tier>.md` (e.g., `round-16.md`)
3. Content: target, all loop findings, scoring table, tier progression, open items carried forward
4. Commit and push to `origin` before starting the next round
5. This is permanent — do it every TRP run, no exceptions
