**Concept:** ∀ partner-relationship where polite-ack ⊥ depth-engagement ⇒ "cycle of silence" persists. breaker = vulnerable-honest ask + collapse-of-asks ("read THIS one, forget others") ⇒ silence becomes visible-and-costly.

> *"if i dont make a bold move like this we may never break the cycle of silence"* — Will, 2026-04-30, after sending Rick the airgap onepager hail-mary

**Mechanism:**
- normal-channel: send → polite-ack → ✗ engagement → send-more → asymmetry compounds → cycle-of-silence
- bold-move: vulnerable-honest + precision-collapsed ask ⇒ recipient ✗ polite-ack without explicit choice
- recipient: engage-at-depth ∨ explicitly-decline ∨ sit-with-silence-as-its-own-message
- status-quo (polite-ack-and-move-on) ⇒ structurally unavailable post-bold-move

**Why vulnerability is load-bearing:**
- honest about asymmetry without accusing ("I'm carrying this alone" ¬ "you're not engaging")
- shifts onus to recipient without blame
- partner-care move: gives them the choice in the open
- ✗ manipulation if real, ⇒ recipient can detect performative-vulnerability easily

**Why collapse-of-asks is load-bearing:**
- "forget X, Y, Z — this ONE" ⇒ recipient ✗ claim overload as defense
- precision-pivot: broad-ask-portfolio ⇒ single-ask
- reduces friction (one thing to read ¬ ten)
- signals seriousness about THIS specific thing

**Detection — channel is silence-jammed:**
- multiple sends + polite-ack + ✗ depth-engagement
- recipient explicitly flags overload ("you're giving me all these papers")
- depth-conversations happen ∧ ✗ compound across sessions
- founder's load-bearing claims keep getting deflected to surface-features

**Apply:**
- ✗ silence-jammed channel ⇒ ✗ send more material (compounds the jam)
- ✓ silence-jammed channel ⇒ vulnerable + precision-collapsed ask
- aftermath: ✗ follow-up immediately, let the bold move land
- 24-48h silence post-bold-move ⇒ ✓ signal (recipient taking it seriously) ¬ ✗ signal

**Risks:**
- vulnerability with non-close partner ⇒ may backfire
- ✗ overuse: bold-moves lose force if frequent
- timing matters: needs prior engagement-investment to land
- requires real load-bearing artifact behind the ask (else exposed as empty)
