**Named as a distinct primitive class by Will, 2026-04-23**, after the settlement-asset LinkedIn reply cycle. Generic "communication" primitives miscalibrate for public social media because:

- **Audiences don't read deeply; they pattern-match on sequence.** Who replies first with apparent authority shapes perception. A stronger counter posted later still loses the impressionable-reader segment that saw the original exchange.
- **Platforms are adversarial by default.** Critics optimize for debunks, not understanding. Leaving a defensible flank open gets it attacked.
- **Pretentious-audience platforms amplify tone mismatches.** "Let me know your thoughts!" reads as amateur on LinkedIn; "lol" reads as flippant. Platform register is load-bearing.
- **Algorithmic amplification rewards engagement shape, not content.** Long substantive replies in the first 90 minutes after a post drive reach in ways that later replies don't.

## Why this is a class, not scattered rules

Each tactic below is cheap in isolation; the class is expensive to skip. Treating them as a coherent set means:
- A single check before any public post: "which class members apply here?"
- New tactics join the class as they're observed under real adversarial conditions.
- Drift-catch: when a reply feels "off" but we can't name why, the class is the vocabulary for diagnosing it.

## Class-level rules

These apply across ALL members:

1. **Sequence is content.** Who posts what when changes the reading. Every tactic factors in the real-time unfolding, not just the standalone merit of the text.
2. **Concede before attacked.** If an attack can be anticipated, it must be pre-empted in the artifact.
3. **Match platform register.** LinkedIn ≠ X ≠ Telegram public ≠ GitHub issue. Voice discipline is per-platform.
4. **Own the frame at the close.** The load-bearing claim sits at the end of any public post/reply so it's the last thing read.
5. **No lax phrasing with "I'll defend it in the thread."** The thread is public; defense should be in the artifact.

## Growth principle

New tactics join when they survive a real adversarial encounter. Patterns that feel clever but haven't been tested don't get in. The class stays load-bearing because every member was paid for with either a public near-miss or a public hit.

## How to apply

Before posting any public reply or post:
1. Check the class members for applicable rules.
2. Run the pre-empt-debate check (adversarial clap-back list).
3. Match register to platform.
4. Confirm the close carries the load-bearing claim.
5. Read it once more imagining a hostile reader — does anything feel landable?

**Never skip step 5.** The hostile reader check is where most drift gets caught.
