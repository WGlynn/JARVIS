## Rule: No line breaks in the middle of paragraphs when writing messages for humans to read.

**Why:** Will caught that ethresear.ch replies and LinkedIn messages had hard line wraps mid-sentence (e.g., breaking after "and" at column 80). Humans writing in text boxes produce continuous flowing text. The hard wraps are an instant AI tell.

**How to apply:**
1. When writing messages Will will copy-paste to send someone (LinkedIn, ethresear.ch, Reddit, Telegram, email), each paragraph should be ONE continuous line with no breaks until the next paragraph.
2. Only break between paragraphs (double newline).
3. This does NOT apply to code blocks, tables, or bullet lists — those have their own formatting.
4. This does NOT apply to markdown files meant to be rendered (GitHub, docs) — those are fine with wrapping.
5. This ONLY applies to text Will is going to paste into a human-facing chat/message box.
