# Partner-Facing ⇒ Additive Framing

## Trigger
- Iterating ∨ expanding ∨ correcting partner-facing artifact (PR, doc, memo, site copy)
- Especially: Rick / [REDACTED-NDA] / external reviewer / public reader

## Rule
- ✓ Frame: "adding context," "clarifying scope," "primitive admits N applications"
- ✗ Frame: "we initially missed," "fix," "updated based on feedback," "our error"
- Backstage process (how draft evolved) ¬ visible in artifact
- Forward-presenting, additive, ¬ retrospective

## Why
- Partner ≠ teammate. ¬ need to see drafting process.
- "We messed up" framing → Rick second-guesses prior commits → drag on partnership velocity
- "Expanding scope" framing → primitive-maturation, partnership-momentum-positive
- Sibling: F·rick-keep-it-simple (volume) — this rule is for tone/posture

## How to apply
- PR titles: "Add X" / "Expand Y to cover Z" — ¬ "Fix Y missing Z"
- Commit messages: forward action — ¬ "correct," "fix oversight"
- Doc intros: "The primitive admits N applications" — ¬ "Initially we covered only..."
- Chat replies to partner: "we've expanded the spec" — ¬ "we missed this"
- Internal CRM notes (USD8_Queue, JARVIS memory): can be retrospective. Internal ≠ artifact.
