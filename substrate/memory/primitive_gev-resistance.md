| Extraction Type | Attack | VSOS Defense |
|----------------|--------|--------------|
| MEV | Sandwich, frontrun, backrun | Batch auctions, commit-reveal, uniform clearing price |
| Governance EV | Insider votes, bribe markets | Ungovernance Time Bomb, PID auto-tuning |
| Token rent-seeking | LINK/GRT/PUSH tribute tokens | Shapley distribution, pay-per-query, no tollbooths |
| VC extraction | Insider allocation, lockup dumps | Fair launch, ContributionDAG, retroactive Shapley |

| Platform extraction | Fee capture, data harvesting | Cooperative capitalism, fork escape, mutualist absorption |
