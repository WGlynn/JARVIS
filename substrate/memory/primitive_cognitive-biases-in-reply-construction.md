**Source**: Kahneman, *Thinking, Fast and Slow*; Tversky & Kahneman prospect theory papers.

**Core insight**: readers are not rational. First exposure anchors subsequent judgments. Vivid examples outweigh statistics. Losses hurt more than equivalent gains. The same claim with different framing lands differently in the reader's mind.

**Tactical application (public threads)**:

1. **Anchoring** — lead with the specific number/claim you want to stick. Later paragraphs refine but don't reset the anchor. Order matters: the first concrete figure becomes the reference point.
2. **Availability** — use concrete examples, not abstract arguments. One vivid case beats ten statistics. "DAI drifted toward USDC backing" lands; "some protocols have composition drift" doesn't.
3. **Loss aversion** — stakes framed as losses avoided outweigh equivalent gains. "You won't get burned by X" > "You'll benefit from Y" for equivalent factual content.
4. **Framing effect** — "90% success" ≠ "10% failure" in reader perception. Choose the frame that matches the substance, not the one that gets you a cheap win.

**Defense (when used against you)**:
- Anchored by the first number someone drops → deliberately generate your own anchor before evaluating.
- Vivid anecdote presented as representative → ask for base rates.
- Loss framing where gain framing would be honest → notice the manipulation.
- Accepting a frame because it came first → explicitly reframe before responding.

**Ethics note**: using these offensively in threads about substantive topics crosses into manipulation. Use for clarity-of-expression, not to weaponize reader irrationality.
