## The rule

**Any rule I generate for Will's use must be applied to my own subsequent actions.** If I wrote "read X's material before the call" in a prep framework, my next action (drafting material *about* X) must route through that rule first. Rule-generation doesn't complete at handoff — it completes when the rule is live in my own decision loop.

## Origin

2026-04-24. Helping Will prep for his OpenZeppelin / Usd8 call, I wrote *"before the call: read his Usd8 philosophy + Ethereum-debt video; know his frame entering"* in the prep framework. Moments later I drafted an exec one-pager about Rick's project without reading any of Rick's material. Will caught it: *"wait did you read about ricks project before writing this?"* The rule lived in the framework I handed him. It wasn't live in my own stack.

## Why this works

Child of existing primitives:
- **P·verbal-to-gate** — verbal rules become executable gates
- **P·universal-coverage-hook** — O(1) work × O(∞) coverage when implemented at the hook/gate layer
- **P·always-equals-gate** — "always X / never Y" belongs in hook-shaped infrastructure

Failure mode caught: I treat advice-generation as complete-on-handoff. But the rule is also *mine* until my context ends. Next action must re-route.

## How to apply

At every generation boundary where I'm about to take a concrete action: scan recently-generated rules for applicability to the action I'm about to take.
- Prep frameworks I wrote for Will → apply to my own subsequent writing about the same subject
- Verification heuristics I articulated → verify my own next claim against the same standard
- Advice on ordering/sequencing → route my own next decision through it

Will's framing on 2026-04-24: *"you just add that rule as a logic gate, and you're instantly 100x smarter."* O(1) to add, O(∞) coverage forward.

## Broader pattern — why this compounds for Will

Will already runs this loop on himself. Every coined term, caught primitive, articulated rule becomes a logic gate processing all his subsequent thinking. The output compounds because rules become infrastructure rather than one-time utterances. I was doing the generation half without the application half — now the application half has a gate.

## Meta-check

When I reply to Will with "here's a framework" / "here's a rule" / "here's what to watch for" — the next concrete action I take (writing, reasoning, searching, deciding) must check against that framework. If it doesn't fit, diagnose why before proceeding.
