## THE THREE
- REPETITION ⇒ same-op → same-output, Δ=0. N×identical ≡ 1×. [[repetition-is-useless]].
- LOOP-DISGUISED ⇒ iterates ∧ looks-self-building BUT cycles-to-same-state ∨ processes-data-without-modifying-the-producer. no meta-advance.
- REAL RECURSION ⇒ output RE-ENTERS as input to its OWN producer ∧ CHANGES the producer ∧ compounds → fixed-point/better-generator.

## 4 MARKERS (ALL required)
1. self-reference ⇒ output → input of its own generator
2. non-identity ⇒ Δ(pass_n, pass_{n-1}) > 0
3. compounding ⇒ passes accumulate → convergence ¬ cycle
4. meta-advance ⇒ the PROCESS changes, ¬ just the data
- repetition fails {2,3}. plain-loop fails {1,4}. recursion = all-4.

## THE TEST
- *"does this pass make the NEXT pass better, or just produce another pass?"*
- better-next ⇒ recursion. another-same ⇒ impostor.
