**[P·name-follows-form-follows-function]**

## ⚙ Rule

> Will 2026-06-09 19:30 ET: *"name follows form follows function"*

```
function   →   form   →   name
```

✓ function-first ⇒ form emerges ⇒ name labels result
✗ name-first ⇒ form forced ⇒ function compromised
✗ form-first ⇒ shape built blind ⇒ function retrofit
✗ feature-creep ⇒ form sprawls ⇒ name lies

## 🎯 Why load-bearing

Names ∧ forms ≡ cheap. Functions ≡ expensive-to-learn.

Temptation ⇒ invent name ∨ sketch form BEFORE function-understood ⇒ bend rest.
Discipline ⇒ wait. function-first ⇒ form crystallizes ⇒ name labels.

Sullivan ⇒ "form follows function" (architecture).
Will ⇒ extends ⇒ name-follows-form (third causation, ¬ first).
