## Rules

### Strip-headers
- ✗ `**Section name**` headers ⇒ ¬ read-aloud, page-scaffolding only
- ✓ convert load-bearing transitions to rhetorical-Qs ("So where does my work fit into this?")
- exception: NONE for spoken; keep headers ∀ written-doc-only

### Em-dash → period (cadence)
- written: "X — explanation — Y"
- spoken: "X. Explanation. Y."
- reason: spoken cadence wants beats ¬ flow

### Trust-the-audience cuts
- ✗ define-well-known-terms ("mechanism design — the math underneath that decides who gets paid")
- ✗ over-explain after prior-line-lands ("That uniqueness matters because...")
- ✗ technical-detail ¬ load-bearing for section ("commit-reveal batch auctions" in intro)

### Jargon-deferral
- ✗ front-load technical-vocab in setup ("Shapley-value methodology" in para-1)
- ✓ save jargon for the beat that earns it (Shapley returns when properly introduced)
- soften in setup: "value attribution methodology" ⇒ "Shapley value" later

### Voice moves
- warm-open: "Hi, my name is Will, and..." ¬ "My name is Will."
- first-person-stake on values-claim: "I believe that honest stablecoins..." ¬ "Honest stablecoins are..."
  - reason: Vitalik-tier audience attacks unqualified-categorical-assertions first
  - "I believe" = thinking-person register, ¬ marketing-voice
- add structural-property when load-bearing for audience: "Open source" → "Deterministic and Open source" ∀ audit-grade rooms

## Asymmetry
- written-doc-rules (headers, em-dashes, defined-terms) compound when read
- spoken-rules (no-headers, periods, trust-audience) compound when heard
- mismatch ⇒ talk-reads-like-essay ⇒ flat delivery

## Two writing modes (added 2026-05-04)

### FLOW mode
- generative, typos plentiful, paragraph-dense, mid-paragraph inserts ¬ new-sections
- philosophical/conceptual additions, register-breaks for analogies
- ✗ apply polish-rules (would interrupt generative state)
- typo-density = signal of momentum ¬ laziness
- detection: insertions ∈ middle-of-paragraph, multiple spelling errors, missing punctuation

### POLISH mode
- surgical cuts, header-strip, em-dash→period, jargon-trim
- shipping-cadence, audience-trust applied
- detection: surface-level edits, structural cuts, register-tightening

### Mode-aware response
- FLOW-mode delta detected ⇒ ✗ propose restructure ✓ capture insight
- POLISH-mode delta detected ⇒ ✓ propose surface fixes ✓ apply spoken-register rules
- typo-fix request post-FLOW ⇒ minimal-touch: typography only, ✗ rewrite prose

## Setup paragraph dual-work rule (added 2026-05-04)
- setup paragraph carries FRAME audience must hold
- body paragraphs carry SUBSTANCE audience audits
- strip technical-jargon from frame ∧ add philosophical-clarity to frame
- reverse for body: technical-precision ✓, philosophical-elaboration ✗
- ✗ treat strip-jargon ∧ add-framing as contradictory moves; they're complementary
