2. Gives Jarvis a phase: "Phase 3 — write all tests. I'll be at the talk until 2pm."
3. Jarvis runs autopilot — codes, tests, commits, pushes. Regular commit messages prove the work timeline to judges.
4. Will comes back, reviews, approves or adjusts, kicks off next phase
5. Repeat. Will's physical presence unlocks networking; Jarvis's continuous presence unlocks build velocity.
