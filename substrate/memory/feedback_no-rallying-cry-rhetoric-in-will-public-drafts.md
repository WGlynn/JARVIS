**Rule**: ∀ Will-public-draft (X / Medium / scripts / decks / pitches) ⇒ amplify via DECLARATION ¬ RALLYING-CRY. Restraint = the register that lands.

**Why**: 2026-05-03 — USD8 hello-world script. Twice tried inspirational amplification, twice cut:
- v1 opener: *"And I'm coming on here today to talk to anyone who's still in crypto despite the hacks..."* ⇒ Will: "too corny to land with twitter folk"
- v2 closer: *"If you've been waiting for this, you've been waiting alongside us. We're done waiting."* ⇒ Will: "too corny again"

⇒ pattern: movie-poster ∨ YouTube-guru-opener ∨ rallying-cry register ⇒ CT BS-detector fires ⇒ ✗ cut.

**Works** (Will-actual movement-register):
- ✓ Declarative: *"That's the bar."* / *"We're building for it."* / *"USD8 is real. The work is real. The math is the work."*
- ✓ Restrained stake-naming: *"Your savings. Your friends' savings."*
- ✓ Plain catalogue: *"No courts. No recovery systems. No cross-border cooperation."*
- ⇒ substance carries conviction; rhetoric ✗ does the work

**Doesn't work**:
- ✗ "If you've been waiting..."
- ✗ "We're done waiting"
- ✗ "...for those who still believe..."
- ✗ "Stand alongside us" / "Join us"
- ✗ Marvel-third-act register

**How**:
- ∀ closer ∨ opener ∨ amplification ⇒ check: movie-poster? cut
- ∀ "if you've been..." / "if you feel..." conditional invitation ⇒ ✗
- ∀ "we're done X" / "we will not Y" collective-rallying ⇒ ✗
- ✓ substance + restraint = lands
- ✗ rhetoric + invitation = CT-cringe

**Anti-patterns I step on**:
- ✗ V-for-Vendetta delivery imitation. Will wants V's WEIGHT (restraint), ¬ V's WORDPLAY (anaphora / exhortation)
- ✗ Declaration-preamble register. Will wants DECLARATIONS (plain weighted), ¬ GRIEVANCE-anaphora
- ✗ Engineering a "moment." Substance carries; when engineered ⇒ Will catches engineering ⇒ reads as forced
