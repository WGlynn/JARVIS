# JARVIS complements the model; it does not compete with it

> Will 2026-06-11 (TG, w/ Rick): *"one day there will be a maximally moral agent, i hand crafted jarvis with that in mind and will continue to. it doesnt need to compete with anything it just needs to align."* + *"our standards in crypto are all time lows."* Ties to the LLM-trajectory-alignment question Will asked same session.

## ⊨ Core thesis
- JARVIS bet on the COMPLEMENT of the model ¬ the model. it never competed with intelligence; it built the persistence + governance + accountability that intelligence LACKS.
- ⇒ model-progress = TAILWIND ¬ headwind. the thing that kills wrappers (better models) STRENGTHENS JARVIS. negative-correlation-with-obsolescence.
- align ¬ compete (Will). same move as [P·cybersec-self-elimination-purpose] (defense=bridge-to-dissolution) + [F·augmentation-dont-replace] at the trajectory level.

## ⇒ Alignment vectors (how the design rides the trajectory)
1. **NL-native substrate** — files/markdown = model's native IO; impedance-free as reasoning improves (Will's given example).
2. **tiered recall** — bigger context ⇏ memory solved (lost-in-middle); semantic/warm recall matters MORE not less.
3. **gates govern BOUNDARIES ¬ reasoning** — smarter model does more inside the rails; capability gains flow THROUGH, never hard-coded out.
4. **test-time-compute** — reasoning-models make WWWD-projection + RSAW + adversarial-verify cheaper+stronger. pre-bet on spend-inference-to-check-yourself.
5. **cheap inference ⇒ more gates affordable** — compose-many-small-gates scales INTO the falling-cost curve.
6. **model fungibility** — substrate-independence (md+git+hooks) owns the non-model layer where durable value accrues; multi-provider bot already routes.
7. **continual-learning** — _system loop (corrections→discipline_map→evolution-proposals→hooks) = file-based online-personalization @ operator level. the ONLY place continual learning is possible without weights.
8. **provenance/safety regulation** — merkle-attestation + hash-chain pre-bet on auditable+tamper-evident agent behavior.

- the endpoint of the capability-trajectory IS the alignment question. as agent → maximally-capable, binding-constraint → maximally-MORAL/aligned.
