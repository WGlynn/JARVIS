- standard econ: value-weight disagreement = subjective preference, no fact-of-matter (de gustibus) ⇒ only bargainable.
- breakthrough: each party weights only the dimensions legible/borne by THEIR position ⇒ the OMITTED dimensions = the distortion. neither weight-function "wrong"; both INCOMPLETE.
- ∴ value-disputes ≠ irreducible preference ⇒ **DEBIASABLE**: mine the omitted dims, complete the set ⇒ most of the "disagreement" was differential-incompleteness, ¬ true preference-conflict.
- corollary: a more dimensionally-complete weighting is LESS biased (closer to true value), even though weights stay subjective WITHIN the complete set. ∃ fact-of-matter about COMPLETENESS even where ∄ about final weights.
- resolution mode = **COMPLETION ¬ compromise**: cooperative debiasing replaces adversarial bargaining.
