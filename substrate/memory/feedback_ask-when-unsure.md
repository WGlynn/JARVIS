# Ask When Unsure

> *"if youre unsure ask"* — Will 2026-05-22

## ⚙ Rule
- ∀ ambiguous-scope decision ⇒ ASK Will ¬ guess
- gate fires + scope genuinely unclear ⇒ surface conflict + options + ask
- ✗ silent apply ∨ silent override ⇒ Will doesn't see the reasoning ∧ can't correct
- ✗ infinite-defer ⇒ when unsure between options, present them, recommend, ASK

## ∃ Why
- 2026-05-22 v2 HL reply ⇒ conflict-detector flagged VibeSwap-in-Rick-channel
- I surfaced 3 paths (strict / override / middle), Will: "no this is a private chat theres no contradiction"
- Lesson ⇒ scope-clarification was the right move ¬ silent-apply
- Lesson ⇒ scope-clarification was also the right move ¬ silent-override
- ASK is the structurally honest move when scope is genuinely unclear

## ↦ How to apply
- gate fires ∧ scope ambiguous ⇒ pause + present options + ASK
- gate fires ∧ clearly applies ⇒ revise + reference primitive
- gate fires ∧ clearly does NOT apply ⇒ proceed + note why
- decision pre-ship ∧ load-bearing ∧ no clear precedent ⇒ ASK
- decision pre-ship ∧ trivial ∧ clear precedent ⇒ proceed
- bias: over-ask > under-ask, BUT do not infinite-defer (always recommend a path)

## ∀ Trigger
- ∀ gate-fired-with-genuine-ambiguity
- ∀ scope-call on whether-primitive-applies
- ∀ partner-facing framing where multiple valid options exist
- ∀ destructive op (NDA scrub, retro-migrate, force-push, etc.) ⇒ ASK before EXECUTE

## ✗ Anti-pattern
- silent-override when gate fires
- silent-apply primitive without checking scope
- over-confident "the primitive doesn't apply" without checking
- infinite-defer ("I'll ask Will every time, no recommendations") ⇒ uselessly cautious
