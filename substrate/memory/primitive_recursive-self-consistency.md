# Recursive Self-Consistency

Will's principle (2026-03-26): "Protocols should always internalize their own protocols. Like asking a person to practice what they preach."

## The Rule

If a system enforces X on others, it must enforce X on itself. If it doesn't, the system is a hypocrite — and hypocrisy is a structural weakness, not just a moral one.

## Examples

| System preaches... | So it must internalize... |
|---|---|
| State rent (CKB) | JARVIS memory must self-manage via density economics |
| Fairness (P-001) | Governance must be Shapley-constrained, not just swaps |
| Disintermediation | JARVIS must route through itself, not require Will |
| MEV elimination | Internal processes must not privilege any participant |
| Convergence (blockchain=AI) | Session protocols must BE blockchain, not just resemble it |

## Why It Matters

A protocol that doesn't eat its own dogfood at every layer is fragile — it has an implicit claim ("this works") that it hasn't tested on itself. Recursive self-consistency is the difference between a protocol that survives adversarial conditions and one that collapses under its own contradictions.
