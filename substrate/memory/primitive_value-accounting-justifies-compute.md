**energy-critique lands ⟺ one-sided ledger.** ⇐ Will 2026-06-16: *"value accounting ⇒ Anthropic can provably justify energy usage where it can."*

- cost = LEGIBLE (joules / tokens / $) ∧ fungible ∧ easy-to-meter.
- value = ILLEGIBLE (non-fungible, heterogeneous per-session) ∧ currently unmeasured.
- ∴ "is it worth the energy" fights on a ledger w/ debit-column only.

**The flip:** measure output-value ⇒ question goes "justify the cost" → "value provably > cost, here's the receipt."
- compute defended on VALUE basis ¬ VOLUME basis.
- token-spent-minting-a-primitive ≠ token-spent-on-weather, yet costed identically ⇒ massive mispricing input-side.

**Load-bearing premise (the crux):** *provably* ⇒ needs a non-gameable value measure (value-oracle). ✗ oracle ⇒ every provider just asserts high-value ⇒ receipt worthless. → [[primitive_value-honest-verifier-is-the-through-line]] (the open challenge).
