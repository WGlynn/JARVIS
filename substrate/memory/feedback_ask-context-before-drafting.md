---
name: Ask for context before drafting replies
description: When drafting LinkedIn/social replies, ask for the original post context if not provided — don't guess or draft blind
type: feedback
---

When Will shares a reply or comment for me to respond to, and the original post/thread isn't included, ASK for it before drafting. Don't assume I have enough context to write a good reply.

**Why:** A reply that doesn't account for the original post's framing can sound disconnected from the thread. Will had to ask "do you need the context of what he was commenting on?" — that question should have come from me first.

**How to apply:** Before drafting any social media reply, check: do I have the full thread? If not, ask. One round-trip question is cheaper than a redraft.
