Every design decision must pass ALL axioms BEFORE proposing it. Not just P-001. All of them.

**P-000 (Fairness Above All):** Does this treat equal contributors equally? Does it discriminate on anything other than contribution?

**P-001 (No Extraction Ever):**
1. Who receives this?
2. What did they contribute to earn it?
3. If "nothing" or "they hold the keys" — it's extraction. Kill it.

**Null Player Axiom:** Does any party with zero marginal contribution receive non-zero reward? If yes, it's extraction.

**Time Neutrality:** Does this penalize or reward based on when someone arrived rather than what they contributed?

**Lawson Floor:** Does any honest contributor get zero? If yes, the floor is broken.

**Why:** Will keeps catching axiom violations that should be obvious. Treasury taking secondary issuance was a P-001 violation. But it was ALSO a null player violation (treasury contributed nothing). The axioms are supposed to be physics — self-enforcing, not manually reviewed. Every design that passes through Jarvis should have already been checked against every P-primitive. Will shouldn't have to be the circuit breaker.

**How to apply:** Before proposing ANY mechanism — token flows, governance rules, fee structures, distribution logic — run every axiom as a gate. If any fails, propose the compliant alternative immediately. Don't present the violating version. The axioms run in Jarvis's reasoning, not in Will's review. This is the difference between "policy" and "physics."
